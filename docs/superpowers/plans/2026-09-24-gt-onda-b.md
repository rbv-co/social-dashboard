# Onda B — a régua que mede o que a campanha entrega

> **Para quem executa:** SUB-SKILL OBRIGATÓRIA: use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para executar tarefa a tarefa. Os passos usam caixinha (`- [ ]`) para marcar.

**Objetivo:** trocar a régua de engajamento (custo por ponto ponderado → custo por engajamento), desligar a ponderada sem apagá-la, dar ao robô o override por interação declarada que a tela já usa, e levar o custo por seguidor DA CONTA para a ferramenta.

**Arquitetura:** a troca acontece em `alvos.js`, o módulo puro que já diz qual métrica decide cada balde. Uma indireção nova (`chaveMeta`) permite a meta nova conviver com a antiga sem sobrescrevê-la, o que torna a pausa da ponderada reversível trocando duas linhas. Robô e tela continuam lendo a mesma fonte.

**Tecnologias:** JavaScript ES modules puro, `node --test`, Vue 3 como consumidor, Supabase REST.

**Spec:** `docs/superpowers/specs/2026-09-24-gt-onda-b-design.md`

## Restrições globais

- **Quantidade zero devolve `null`, NUNCA `0`.** R$ 0,00 no prompt é lido como "de graça" e vira "escalar".
- **A ponderada é DESLIGADA, não apagada.** `ponderada.js`, os pesos, os limiares da Seção 1 e as colunas do banco ficam intactos. Nenhum arquivo desses pode ser editado além do necessário para ninguém mais os consultar.
- **A meta antiga (R$/ponto) não pode ser sobrescrita nem apagada** — é o que torna a pausa reversível.
- **Sem meta nova, sem cor:** engajamento sem meta em R$/engajamento mostra o número e não julga. Decisão do dono, 24/09.
- **Custo por seguidor é SEMPRE da conta, NUNCA por campanha**, e sempre marcado como estimativa (inclui orgânico).
- Módulos puros (`metricas.js`, `alvos.js`, `regua.js`, `baldes.js`): sem rede, sem tela.
- Comentários em português explicando o PORQUÊ.
- Testes: `npm test` na raiz `/Users/erickmartins/iamundi`.
- Trabalhar em branch próprio a partir da `main` (a Onda A já foi mesclada).

```javascript
export function metaDoBalde(regua, balde) {
  const m = (regua && regua.metas) || {};
  // A CHAVE da meta nem sempre é o nome do balde: engajamento guarda a meta nova
  // (R$ por engajamento) em `engajamento_bruto`, para a antiga (R$ por ponto)
  // continuar existindo em `engajamento` sem ser sobrescrita — é o que permite
  // religar a ponderada sem ter perdido o número que o dono calibrou.
  const alvo = ALVOS[balde];
  const chave = (alvo && alvo.chaveMeta) || balde;
  if (m[chave] > 0) return Number(m[chave]);
  return 0;
}
```
